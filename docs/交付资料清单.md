# 图片智能处理服务交付资料清单

> 整理日期：2026-09-11

## 1. 接口联调

对外联调统一发送以下主文档：

- [客户接口联调文档](联调接口.md)：完整说明 Base URL、鉴权、创建任务、回调验签、补偿查询、错误码和验收清单。
- [公司服务端接入说明](company-api.md)：供内部研发快速查看稳定接口边界和安全约束。

当前推荐协议为 `customer_v1`：客户服务端通过 URL 图片 + JSON 创建异步任务，图片服务处理完成后主动回调。不要把 [历史 multipart 联调文档](图片智能处理服务-客户联调文档.md) 作为新项目的主协议。

联调密钥和回调签名密钥必须通过受控渠道单独传递，不得写入文档、聊天记录或代码仓库。

## 2. 服务器部署与更新

运维交付统一发送以下主文档和配套文件：

- [客户服务器部署与更新操作手册](客户服务器部署与更新操作手册.md)：首次部署、环境变量、HTTPS、日常更新、验证、回滚、备份与故障处理。
- [从本地安全更新生产服务器](local-production-deploy.md)：已有服务器通过 Windows 发布机一键更新的操作说明。
- [生产发布与恢复手册](production-runbook.md)：发布门禁、恢复和备份要求的精简版。
- [Harbor 首次部署说明](harbor-first-deployment.md)：仅在交付方明确使用 Harbor 时发送。
- [`docker-compose.prod.yml`](../docker-compose.prod.yml)：生产服务拓扑。
- [`.env.production.example`](../.env.production.example)：生产环境变量模板，只能复制后在服务器本地填写密钥。
- [`scripts/customer-compose.sh`](../scripts/customer-compose.sh)：自动加载生产环境变量的 Compose 命令入口。
- [`scripts/deploy-production.ps1`](../scripts/deploy-production.ps1)：测试、构建、推送、服务器检查、部署和失败回滚脚本。
- [`一键更新服务器.cmd`](../一键更新服务器.cmd)：Windows 一键发布入口。

生产环境禁止上传 `.env` 或 `.env.production` 实际文件，禁止在服务器现场构建镜像，禁止使用 `latest`。API、网关、分类、渲染和 Web 五个镜像引用必须在更新或回滚时作为同一版本整体切换。

## 3. 交付前核对

- 接口联调方只收到 `INTEGRATION_API_KEY`，不能收到内部 `API_KEY`。
- 回调签名密钥与接口密钥独立生成，并确认双方使用原始请求体字节验签。
- 新版本 API 和 Web 镜像均已通过 CI，并记录完整 Git SHA 或不可变 digest。
- 发布前已备份 PostgreSQL、MinIO 数据和生产配置，且记录上一健康版本。
- 发布后 `/health/ready` 返回 HTTP 200，所有长期运行容器健康，一次性容器为 `Exited (0)`。
- 使用 1 至 3 张图片完成创建、处理、回调、验签和下载的全流程验收。

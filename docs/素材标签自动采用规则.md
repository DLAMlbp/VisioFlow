# 素材标签自动采用规则

2026-09-08 更新，`library_similarity_v2` 配置版本 14。

- 保留图片向量、内容特征和素材组聚合的综合评分方式。
- 选取综合匹配分最高的候选组；分数大于或等于配置的采用线（当前 70%）时，继承该组完整标签。
- 综合分相同时先比较图片相似度；仍相同则按素材 ID 升序选择，确保结果稳定。
- 候选组间差距、语义支持状态和泛化组支持数量不再作为自动采用的额外门槛，语义加分不再改变最终候选次序。
- 低于采用线或没有候选时不打标签，不提供人工改判或 Shadow 模式。
- `candidate_margin` 仅作为诊断字段保留，表示前两组综合分差；旧配置中的差距及额外采用门槛字段保留兼容，但不再参与判定。
- 页面展示的综合分和采用线，与自动判定使用的分数及阈值一致。
- 历史结果不会因发布自动改写；重新匹配时使用新规则。历史已回调任务不得自动补发，以免重复业务处理。

该策略优先按最高分覆盖标签，分数接近或语义不明确时也可能自动采用，需通过人工抽检评估标签准确率。
